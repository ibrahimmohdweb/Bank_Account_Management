# Bank_Account_Management
# Internship Project – Project 3

This project is a **Java-based Bank Account Management System** developed as part of an internship task.  
It uses **Java Collections** to manage multiple bank accounts efficiently through a command-line interface.

# Features
- Create new bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Store and manage account data using Java Collections
- Simple and user-friendly CLI interface

# Technologies Used
- Java
- Java Collections Framework
- Object-Oriented Programming (OOP)

# How to Run
1. Install Java (JDK 8 or above).
2. Clone this repository.
3. Navigate to the `src` folder.
4. Compile the files

# Learning Outcomes
- Understanding Java Collections
- Applying OOP concepts
- Handling user input and exceptions
- Building real-world console applications
